# ✈️ AI Travel Itinerary Planner

Built by [Yamini](https://github.com/Yamini1025) and [Taanyaa](https://github.com/taanyaaharidassprasad06).


An AI-powered travel planning app that turns a few trip details into a fully researched, day-by-day itinerary with real flights, real hotels, real attractions and restaurants, and a personalized schedule generated by AI.

---

## 📖 Overview

This app lets a user describe a trip (starting point, destination, dates, budget, trip type, and preferences), then:

1. **Validates** the destination and starting point against real airport/location data.
2. **Validates** free-text preferences (dietary, attractions, general notes) using an LLM, rejecting gibberish while accepting natural language.
3. **Searches** live flight, hotel, attraction, and restaurant data for the trip.
4. Lets the user **pick a flight and hotel** from the real results.
5. **Generates a complete day-by-day itinerary** with an AI model, featuring timed activities, realistic travel times, meal suggestions, and a pace/budget that matches what the user asked for.
6. Displays the itinerary in a clean, day-by-day view alongside a trip summary.

Trips are saved locally in the browser, so users can revisit, search, or delete past itineraries.

## 🧱 Tech Stack

**Languages**
- JavaScript (JSX) - frontend
- Python - backend
- CSS - styling
- HTML (via JSX/Vite)

**Frontend**
- [React](https://react.dev/) (Vite)
- [React Router](https://reactrouter.com/) for client-side routing
- Browser `localStorage` for trip persistence

**Backend**
- [FastAPI](https://fastapi.tiangolo.com/) (Python) REST API
- [Pydantic](https://docs.pydantic.dev/) for request/response validation
- CORS middleware configured for local development

**AI / Data**
- [Google Gemini](https://ai.google.dev/) (`gemini-3.5-flash` via `google-generativeai`) for:
  - Validating user-entered preferences (catching nonsensical/irrelevant input)
  - Generating the final structured, day-by-day itinerary as JSON
- [SerpApi](https://serpapi.com/) for real-world travel data:
  - `google_flights_autocomplete` - resolving city names to airport IDs and validating locations
  - `google_flights` - outbound and return flight search
  - `google_hotels` - hotel search with pricing, rating, and location
  - `google_local` - attraction and restaurant search, filtered by user preferences

---

## 🏗️ Architecture

React (Vite) Frontend ⇄ FastAPI Backend ⇄ SerpApi (flights, hotels, attractions, restaurants) ⇄ Gemini API (preference validation + itinerary generation)

The frontend never talks to third-party APIs directly - every external call (SerpApi, Gemini) is called through the FastAPI backend, which also shapes and cleans the data before returning it.

---

## ✨ Features

- 📍 **Location validation** - starting point and destination are checked against real airport/location data before a search ever runs.
- 🧠 **AI preference validation** - dietary, attraction, and general preferences are checked for relevance before being used, with helpful inline error messages if something doesn't make sense.
- 🔎 **Live travel search** - real flights, hotels, attractions, and restaurants pulled at request time, tailored to the destination and preferences.
- 🎯 **Preference-aware filtering** - attraction and restaurant searches incorporate the user's stated interests and dietary needs.
- 💺 **Flight & hotel selection** - users pick from actual search results, not placeholders.
- 🗓️ **AI-generated itinerary** - a day-by-day plan with:
  - Specific times (12-hour format)
  - Estimated activity durations
  - Realistic travel time between stops
  - Budget-aware pacing (Budget-friendly / Mid-range / Luxury)
  - Trip-type awareness (adult activities, kid-friendly, or a balanced mix)
  - No invented businesses, prices, or ratings — only what came back from search
- 🗂️ **Trip management** - trips are saved locally, searchable by destination or title, and can be deleted.
- ⏳ **Loading states** - dedicated popups while searching for flights/hotels and while generating the itinerary.

## ⚙️ Local Development

### Prerequisites
- Python 3.10+
- Node.js 18+
- A [SerpApi](https://serpapi.com/) API key
- A [Google Gemini](https://ai.google.dev/) API key

### 1. Backend

cd backend
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

pip install fastapi uvicorn python-dotenv google-generativeai serpapi pydantic

Create a `.env` file in the backend directory:

GEMINI_API_KEY=your_gemini_api_key
SERPAPI_KEY=your_serpapi_key

Run the server:

uvicorn main:app --reload

### 2. Frontend

cd frontend
npm install
npm run dev

The frontend expects the backend running at `${import.meta.env.VITE_API_BASE_URL}`.

## 🚧 Known Limitations / Future Improvements

- Trip data is stored in `localStorage` only - no user accounts or persistent database yet.
- No authentication layer.
- API keys and base URLs are currently hardcoded to `localhost` for local development.
- No retry/backoff logic around third-party API failures beyond basic error handling.
